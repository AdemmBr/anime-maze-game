# Labyrinth Game

[Français](#français) | [English](#english)

## Français

Jeu de labyrinthe en Pygame, fait au lycée. On choisit un personnage et il faut finir les niveaux avant de tomber à court de temps ou de vies.

\- Flèches pour se déplacer, chaque mur touché coûte une vie.\
\- Settings : personnage et difficulté (Easy / Normal / Hard).\
\- Levels : accès direct à un niveau.

```bash
pip install pygame
git clone https://github.com/AdemmBr/anime-maze-game.git
python anime-maze-game/labyrinthe/JeuLabyrinthe.py
```

Les niveaux sont dans `labyrinthe/Niveaux/`, un fichier texte par niveau (`:` = chemin, `m` = mur).

## English

Maze game in Pygame, made in high school. Pick a character and clear the levels before you run out of time or lives.

\- Arrow keys to move, every wall you hit costs a life.\
\- Settings: character and difficulty (Easy / Normal / Hard).\
\- Levels: jump straight to a level.

```bash
pip install pygame
git clone https://github.com/AdemmBr/anime-maze-game.git
python anime-maze-game/labyrinthe/JeuLabyrinthe.py
```

Levels live in `labyrinthe/Niveaux/`, one text file per level (`:` = path, `m` = wall).
